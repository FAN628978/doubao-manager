API 接入

安全提示：当前版本没有用户认证，仅供本机使用。不要把监听地址改为 0.0.0.0，也不要将端口暴露到公网。
常用接口
完整请求和响应以 Swagger 为准
GET
/api/accounts

读取账号档案列表。

POST
/api/accounts

获取分镜任务和视频关联状态。

/api/jobs

打开关联浏览器并返回提示词，等待人工粘贴和提交。

POST
/api/jobs/{id}/upload

任务工具

任务执行设置

自动：新任务建单后立即交给调度器，自动配置、提交、确认、下载并回推服务器；异常时转人工。
手动：新任务只进入“待处理”，不占用调度名额；在任务列表点“▶ 进入调度”后才交给调度器。放行后若暂无空闲名额，任务仍留在“待处理”，按钮会变为“⏳ 已放行 · 排队中”。注意：建单时指定了账号的任务会立即预占当日额度——额度与处理名额是两回事，未放行期间额度也已占用。
0 表示不限数量；设置为 N 时，机器同时最多执行 N 个任务。同一账号和不同账号的自动任务都可在各自独立标签页中并行执行；每个执行中的任务占一个名额，转入“异常待人工”或结束（已下载/失败）时释放。
忽略本地额度判断已关闭 · 执行本地额度判断
关闭时会阻止本地剩余额度不足的任务；开启后所有自动任务优先选择剩余最多的未暂停账号，并在建单、启动、恢复和确认时跳过本地额度不足判断。豆包平台实际额度仍可能拒绝生成。
启用 Claude 自动恢复已关闭 · 异常任务转人工处理
开启后，异常任务会交给 Claude CLI 检查并尝试安全恢复；关闭后不再启动新的 Claude 恢复，正在运行的 Claude 恢复也会停止。
设置保存在本机并立即生效。降低数量不会中断已经在处理的任务；达到上限后，新任务会留在“待处理”等待名额。
