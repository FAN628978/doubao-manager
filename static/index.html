DEVELOPER API / 04

API 接入

独立服务默认运行在本机 127.0.0.1:8765，可供漫剧系统通过 HTTP 调用。
安全提示：当前版本没有用户认证，仅供本机使用。不要把监听地址改为 0.0.0.0，也不要将端口暴露到公网。
常用接口
完整请求和响应以 Swagger 为准
GET
/api/accounts

读取账号档案列表。

POST
/api/accounts

创建账号档案，自动分配独立 profile 目录；名称留空时使用默认命名 doubao01、doubao02…

GET
/api/accounts/suggested-name

返回下一个默认账号名。

DEL
/api/accounts/{id}

删除账号档案。登录资料默认移入 data/trash/，加 ?purge_data=true 彻底删除；任务与已归档视频保留。

GET
/api/jobs

获取分镜任务和视频关联状态。

POST
/api/jobs

创建任务，传入 project_id、episode_id、shot_id、prompt、account_id。

POST
/api/jobs/{id}/prepare

打开关联浏览器并返回提示词，等待人工粘贴和提交。

POST
/api/jobs/{id}/upload

通过 multipart/form-data 上传视频并归档。

GET
/api/jobs/{id}/video

下载或读取已归档视频。

POST
/api/v1/videos/generations

按选定账号创建网页版生成任务，返回任务 ID。

GET
/api/v1/videos/generations/{id}

查询网页生成任务状态。

创建任务示例
POST /api/jobs · Content-Type: application/json
{ "project_id": "飘香旺铺", "episode_id": "第01集", "shot_id": "镜头01", "prompt": "在这里填写分镜提示词", "account_id": "acc_替换为实际账号ID" }
本模块不需要漫剧系统共享浏览器 Cookie。系统只需保存任务 ID，并通过 API 查询任务状态与视频路径即可。
